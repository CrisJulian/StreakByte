LESSON 02 · HARDWARE BASICS

The motherboard

GOAL: Find and explain the main sockets, slots and connectors on a motherboard.

01 // CORE DEFINITIONS
CPU socket

The place where the CPU sits on the board. Names such as AM5 and LGA 1700 come from pin layout — your CPU must match the socket.

DIMM & PCIe x16 slots

DIMM slots hold RAM sticks with locking clips at both ends. The longest PCIe x16 slot normally houses the graphics card.

M.2 slot

A compact flat connector directly on the board for fast NVMe solid-state drives — no separate power or SATA cables needed.

Rear I/O panel

The external bank of USB, display, audio, and Ethernet ports along the rear edge of the motherboard.

02 // BOARD SCHEMATIC
KEY POINTS
  • Verify CPU socket compatibility before buying parts.
  • Use dual-channel slots A2 & B2 first for two RAM sticks.
  • Never force a connector — match key notches first.
COMMON MISTAKES
  • Forgetting the rear I/O shield before screwing the board in.
  • Putting the graphics card in a shorter x4 slot instead of x16.
  • Missing a case standoff under the board, causing a short.
